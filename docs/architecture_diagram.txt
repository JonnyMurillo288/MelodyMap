ALGORITHM COMPARISON
--------------------

BFS (Breadth-First Search)
┌────────────────────────────────────────┐
│  Queue (FIFO)                          │
│  ┌───┬───┬───┬───┬───┬───┐            │
│  │ 1 │ 2 │ 3 │ 4 │ 5 │...│            │
│  └───┴───┴───┴───┴───┴───┘            │
│                                        │
│  Order: Level by level                │
│  Cost: Depth only                     │
│  Explores: ~5000 nodes (depth 4)      │
└────────────────────────────────────────┘

A* (Best-First Search)
┌────────────────────────────────────────┐
│  Priority Queue (Min-Heap)             │
│       ┌────┐                           │
│       │ 42 │ F=2.1                     │
│      ┌┴──┬─┴┐                          │
│      │15 │ 87│ F=2.5                   │
│     ┌┴┐ ┌┴┐                            │
│     │3│ │9│...                         │
│                                        │
│  Order: Best F score                  │
│  Cost: F = G (hops) + H (embedding)   │
│  Explores: ~2000 nodes (depth 4)      │
└────────────────────────────────────────┘


HEURISTIC CALCULATION
---------------------

Given: Current artist C, Target artist T

1. Lookup embeddings:
   C_emb = [0.5, 0.3, -0.2, ..., 0.8]  (32 dims)
   T_emb = [0.6, 0.4, -0.1, ..., 0.7]  (32 dims)

2. Compute cosine similarity:
   cos(C, T) = (C · T) / (|C| × |T|)
             = 0.95  (range: -1 to 1)

3. Convert to distance:
   h(C, T) = 1 - cos(C, T)
           = 1 - 0.95
           = 0.05

4. Priority in queue:
   F = G + H
     = 2 (hops from start) + 0.05 (embedding distance)
     = 2.05

   Lower F = Higher priority

KEY CONCEPTS
------------

1. Node2Vec: Random walk + Skip-gram
   - Samples paths through collaboration graph
   - Learns embeddings that capture network structure
   - Artists who collaborate often → similar embeddings

2. A* Search: Best-first + Heuristic
   - Priority queue ordered by F = G + H
   - G = actual cost from start (# hops)
   - H = estimated cost to goal (embedding distance)
   - Guaranteed shortest path if H never overestimates

3. Cosine Similarity: Angle between vectors
   - Ignores magnitude, only direction
   - Perfect for normalized embeddings
   - Fast to compute (32 multiply-adds)

4. Heuristic Function: Distance estimate
   - Input: current artist ID, target artist ID
   - Output: estimated "cost" to reach target
   - Good heuristic → fewer nodes explored


LIMITATIONS & FUTURE WORK
--------------------------

Current:
✓ Uniform edge costs (all collaborations = 1 hop)
✓ Static embeddings (trained once)
✓ Single heuristic (cosine distance only)

Future Improvements:
□ Weighted edges (collaboration strength)
□ Learned heuristic (ML model predicts hop distance)
□ Bidirectional A* (search from both ends)
□ Dynamic embeddings (update as graph changes)
□ Multiple heuristics (combine embedding + graph features)
