EMBEDDING LOADING METHODS - VISUAL COMPARISON
==============================================

TWO LOADING METHODS
-------------------

┌─────────────────────────────────────────────────────────────┐
│                     METHOD A: CSV FILE                       │
└─────────────────────────────────────────────────────────────┘

  Jupyter Notebook               CSV File               Go Application
  ┌────────────┐                ┌───────┐              ┌──────────────┐
  │ PecanPy    │   to_csv()     │ /tmp/ │  LoadFromCSV │ Embedding    │
  │ Node2Vec   │───────────────▶│ artist│─────────────▶│ Store        │
  │            │   583K rows    │ embed │              │              │
  │ Train      │                │ .csv  │              │ 150 MB RAM   │
  └────────────┘                └───────┘              └──────────────┘

  Code:
    search.InitEmbeddings("/tmp/artist_embeddings.csv")

  Pros:
    ✓ Simple file-based approach
    ✓ No database dependency for loading
    ✓ Easy to inspect/debug

  Cons:
    ✗ File management required
    ✗ Can get out of sync
    ✗ Extra deployment artifact


┌─────────────────────────────────────────────────────────────┐
│                  METHOD B: DATABASE (NEW!)                   │
└─────────────────────────────────────────────────────────────┘

  Jupyter Notebook            PostgreSQL              Go Application
  ┌────────────┐             ┌──────────┐            ┌──────────────┐
  │ PecanPy    │ INSERT INTO │ artist_  │ LoadFromDB │ Embedding    │
  │ Node2Vec   │────────────▶│ embed_   │───────────▶│ Store        │
  │            │  583K rows  │ n2v      │            │              │
  │ Train      │ UPSERT      │          │            │ 150 MB RAM   │
  └────────────┘             └──────────┘            └──────────────┘

  Code:
    store, _ := search.Open("")
    search.InitEmbeddingsFromDB(store)

  Pros:
    ✓ No file management
    ✓ Always up-to-date
    ✓ Production-ready
    ✓ Simpler deployment

  Cons:
    ✗ Requires database connection
    ✗ One more query on startup

NULL HANDLING
-------------

Database can have NULL values, CSV cannot.

Loading logic:

┌─────────────────────────────────────────────┐
│ For each row:                               │
│                                             │
│   Scan into sql.NullFloat64                │
│                                             │
│   ┌───────────────────┐                    │
│   │ Is value Valid?   │                    │
│   └────────┬──────────┘                    │
│            │                                │
│    ┌───────┴──────┐                        │
│    │              │                        │
│   YES             NO                       │
│    │              │                        │
│    ▼              ▼                        │
│  Use            Use                        │
│  Float64        0.0                        │
│    │              │                        │
│    └──────┬───────┘                        │
│           │                                 │
│           ▼                                 │
│    Store in embedding[i]                   │
└─────────────────────────────────────────────┘


CODE COMPARISON
---------------

Old Code (CSV only):
┌─────────────────────────────────────────────┐
│ import "github.com/.../internal/search"    │
│                                             │
│ func main() {                               │
│     // Load embeddings                     │
│     err := search.InitEmbeddings(           │
│         "/tmp/artist_embeddings.csv",      │
│     )                                       │
│     if err != nil {                         │
│         log.Fatal(err)                      │
│     }                                       │
│                                             │
│     // Use A* search                        │
│     // ...                                  │
│ }                                           │
└─────────────────────────────────────────────┘

New Code (Database):
┌─────────────────────────────────────────────┐
│ import "github.com/.../internal/search"    │
│                                             │
│ func main() {                               │
│     // Connect to database                 │
│     store, _ := search.Open("")            │
│     defer store.Close()                     │
│                                             │
│     // Load embeddings                     │
│     err := search.InitEmbeddingsFromDB(     │
│         store,                              │
│     )                                       │
│     if err != nil {                         │
│         log.Fatal(err)                      │
│     }                                       │
│                                             │
│     // Use A* search                        │
│     // ...                                  │
│ }                                           │
└─────────────────────────────────────────────┘

MEMORY LAYOUT
-------------

In-Memory Structure (same for both methods):

GlobalEmbeddingStore
┌─────────────────────────────────────────────────┐
│ mu: RWMutex (thread safety)                     │
├─────────────────────────────────────────────────┤
│ embeddings: map[string][]float64                │
│                                                 │
│   "1"    → [0.546, 0.498, 0.394, ..., -0.629]  │
│   "10"   → [0.607, 0.566, 0.415, ..., -0.581]  │
│   "1000" → [0.117, 0.256, 0.149, ..., -0.421]  │
│   ...                                           │
│   (583,000 entries)                             │
├─────────────────────────────────────────────────┤
│ dimension: 32                                   │
└─────────────────────────────────────────────────┘

Total Memory: ~150 MB
  = 583,000 artists × 32 floats × 8 bytes

USE CASES
---------

Use CSV when:
  • Testing locally
  • Database not available
  • Need to inspect embeddings manually

Use Database when:
  • Production deployment
  • Embeddings updated frequently
  • Want simpler deployment
