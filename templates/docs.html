Getting Started

The Interlude API provides ML-powered artist collaboration predictions, synthetic track generation, and music intelligence data. All endpoints are under /api/v1/.

1. Get an API Key

POST /api/v1/auth/register 
curl -X POST {{BASE_URL}}/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email": "you@example.com"}'

Returns your API key once. Save it securely. Free tier: 100 requests/hour.

2. Authenticate

Include your API key in every request:

curl -H "X-API-Key: YOUR_KEY" {{BASE_URL}}/api/v1/health

3. Response Format

All endpoints return a standard envelope:

{
  "data": { ... },
  "meta": {
    "model_version": "v5",
    "latency_ms": 42.3,
    "cached": false,
    "request_id": "uuid"
  }
}

Prediction Endpoints

POST /api/v1/predict/connection

Predict the collaboration probability between two artists.

Request Body

src_artiststring, requiredArtist name, MBID, or integer ID
dst_artiststring, requiredArtist name, MBID, or integer ID
model_versionstring, optionalModel version (v1, v3, v5). Default: v5
limitint, optionalNumber of synthetic tracks to generate (1-25, default 5)
Example
curl -X POST {{BASE_URL}}/api/v1/predict/connection \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "src_artist": "Radiohead",
    "dst_artist": "Kendrick Lamar"
  }'
Response
{
  "data": {
    "src_artist": "Radiohead",
    "dst_artist": "Kendrick Lamar",
    "src_name": "Radiohead",
    "dst_name": "Kendrick Lamar",
    "probability": 0.72,
    "tracks": [1042, 1043, 1044, 1045, 1046],
    "features_used": {"cos_sim": 0.43, "shared_neighbors": 12, ...}
  },
  "meta": {"model_version": "v5", "latency_ms": 234.5, "cached": false}
}
POST /api/v1/predict/neighbors

Find the top predicted collaborators for any artist. Uses cached predictions when available (fast path) or runs the full ML pipeline (slow path).

Request Body

artiststring, requiredArtist name, MBID, or integer ID
limitint, optionalNumber of neighbors (1-100, default 20)
min_probabilityfloat, optionalMinimum probability threshold (0.0-1.0)
model_versionstring, optionalModel version. Default: v5
Example
curl -X POST {{BASE_URL}}/api/v1/predict/neighbors \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"artist": "Drake", "limit": 5}'
POST /api/v1/predict/batch

Bulk prediction for up to 1,000 artist pairs in a single request.

Example
curl -X POST {{BASE_URL}}/api/v1/predict/batch \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "pairs": [
      {"src": "Drake", "dst": "Taylor Swift"},
      {"src": "Radiohead", "dst": "Bjork"},
      {"src": "Kendrick Lamar", "dst": "SZA"}
    ]
  }'
POST /api/v1/predict/compare

A/B test the same artist pair across multiple model versions. Compare v1 (basic logistic), v3 (tuned), and v5 (PU learning) side-by-side.

Example
curl -X POST {{BASE_URL}}/api/v1/predict/compare \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "src_artist": "Frank Ocean",
    "dst_artist": "Tame Impala",
    "versions": ["v1", "v3", "v5"]
  }'

Scenario & Discovery

POST /api/v1/explore/what-if

The "What would happen if X and Y collaborated?" endpoint. Takes 2-10 artists, generates all pair combinations, predicts probabilities, creates synthetic tracks, and finds matching real recordings.

Request Body

artistslist[string], required2-10 artist names or IDs
scenarioobject, optionalConstraints: genre_target, popularity_range, mood_target
num_tracksint, optionalSynthetic tracks per pair (default 5)
num_similarint, optionalSimilar real tracks per pair (default 5)
Example
curl -X POST {{BASE_URL}}/api/v1/explore/what-if \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "artists": ["Billie Eilish", "The Weeknd", "Daft Punk"],
    "num_tracks": 3,
    "num_similar": 3
  }'
GET /api/v1/trends/daily

Pre-computed daily featured predictions across 12 genres. Updated every day at 12:00 PM EST.

Query Parameters

datestring, optionalYYYY-MM-DD (default: today)
genrestring, optionalFilter by genre (rock, pop, jazz, etc.)
limitint, optionalNumber of results (default 5)

Track Generation

POST /api/v1/generate/tracks

Generate synthetic track features using the CVAE model. The model produces 62 features covering genre, mood, timbre, rhythm, danceability, and more.

Request Body

src_artiststring, requiredSource artist
dst_artiststring, requiredDestination artist
num_tracksint, optionalTracks to generate (1-20, default 5)
model_versionstring, optionalCVAE version (default: v1)
POST /api/v1/generate/playlist

Find real recordings similar to synthetic tracks using Aitchison distance on genre distributions.

Request Body

synthetic_track_idslist[int], requiredTrack IDs from /generate/tracks
num_similarint, optionalSimilar tracks per synthetic (1-25, default 5)

Artist Intelligence

GET /api/v1/artist/{id}/profile

Full artist profile aggregating MusicBrainz metadata, Last.fm popularity, genre proportions (4 taxonomies), collaboration network, Spotify linkage, and embedding availability.

Example
curl {{BASE_URL}}/api/v1/artist/Radiohead/profile \
  -H "X-API-Key: YOUR_KEY"
GET /api/v1/dataset/export

Download prediction data as CSV or Parquet. Filter by genre, probability range, and model version. Requires Researcher tier or above (admin can export on free tier).

Query Parameters

formatstringcsv or parquet (default: csv)
genrestringFilter by genre
min_probabilityfloatMinimum probability (0.0-1.0)
limitintMax rows (default 10,000)
model_versionstringFilter by model version
