API Endpoints

All endpoints available at /api/v1/ — Full documentation with examples

POST /predict/connection Predict collaboration probability between two artists
POST /predict/neighbors Top-k predicted collaborators for an artist
POST /predict/batch Bulk predictions for up to 1,000 artist pairs
POST /predict/compare A/B test predictions across model versions
POST /explore/what-if "What if X and Y collaborated?" full scenario
POST /generate/tracks Generate synthetic track features via CVAE
POST /generate/playlist Find real tracks matching synthetic predictions
GET /artist/{id}/profile Full artist profile with genres, popularity, collabs
GET /trends/daily Pre-computed daily featured predictions
GET /dataset/export CSV/Parquet download of prediction data
