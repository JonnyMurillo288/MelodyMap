API Endpoints

Documentation and API usage — all endpoints available at /api/v1/

POST /api/v1/predict/connection Predict collaboration probability between two artists
POST /api/v1/predict/neighbors Top-k predicted collaborators for an artist
POST /api/v1/predict/batch Bulk predictions for up to 1,000 artist pairs
POST /api/v1/explore/what-if "What if X and Y collaborated?" — synthetic tracks scenario
POST /api/v1/explore/synthetic-track-features Synthetic tracks with popularity, instrumentation, and lyric analysis
POST /api/v1/generate/tracks Generate synthetic track features via CVAE

Input / Output Formats

All endpoints accept and return JSON. Authentication via X-API-Key header.
